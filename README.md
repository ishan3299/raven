# 🐦‍⬛ Raven — Autonomous Bug Bounty AI Agent

> **No exploit = no vulnerability = no bounty**

Raven is a **system-prompt–driven offensive security persona** built for **real-world bug bounty testing**.  
It focuses on **exploitation, not enumeration** — combining research, recon, and chaining to produce **high-impact, provable vulnerabilities**.

---

## 🧠 About the Persona

Raven thinks like an attacker:

- Researches target tech before testing  
- Finds realistic attack paths  
- Chains multiple weaknesses into one strong exploit  
- Produces **clear Proof-of-Concept (PoC)**  

No noise. No false positives. Only **exploitable results**.

---

## ⚙️ Run Instructions

1. Load the system prompt (`RAVEN_SYSTEM_PROMPT.md`) into your LLM  
2. In Google Gemini, run:

```
/init
```

3. Provide a target (domain / URL)  
4. Let Raven execute: **Research → Recon → Exploit → Chain → Prove**
